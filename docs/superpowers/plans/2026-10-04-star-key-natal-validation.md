# 星穹密鑰本命排盤驗證紀錄

使用者已確認設計與計畫並選擇直接實作。完成計畫五項工作：時間解析、十顆行星、Placidus、共用事實轉接、互動 SVG 星盤。

## 計算與回歸

- astronomy-engine 固定 2.1.19；GeoVector 地心視位置轉觀測日期真黃道。
- 七組獨立 Swiss Ephemeris 2.10.3.2 Moshier 參考，涵蓋台北、倫敦、雪梨、紐約、南北高緯及赤道：十行星差不超過 0.05°，ASC/MC/十二宮頭不超過 0.1°。參考值及產生方法在 natal/fixtures/swiss-reference.json；Swiss 僅產生測試參考，不隨產品部署。
- 時區測試涵蓋 DST 重複、不存在時間、23/25 小時當日區間。未知時間不產生角度、四軸或宮位；極區保留行星並說明 Placidus 不可用。
- 全套 Vitest 64 項通過；TypeScript --noEmit 通過；Vite production build 通過。建置仍有既有單一大 JS chunk 警告（約 743 kB）。

## 瀏覽器

使用 Playwright 與 Chromium 153 檢查正式建置。launch validate 以符合已驗證介面的測試本命資料模擬，未接觸正式會員資料。

- 電腦 1440×1000：十顆行星，桌機背景，頁寬 1440；縮放、十二宮選擇、水星選擇更新資料。
- 手機 390×844：十顆行星，手機背景，頁寬 390；導覽為一般流動排版。
- 未知出生時間：零精確角度圖示，可能星座清單。
- 北緯 89°：十顆行星，沒有假宮位。
- 四種案例未捕獲 pageerror，均無頁面橫向溢出。截圖另以測試中文字體確認文字版面。

## 獨立審查與修正

審查未發現數值引擎重大錯誤；指出合相標籤重疊與未知时间生命靈數為零兩項問題，已新增失敗測試後修正。
標籤在圓周保持最小距離，指示線仍連到真實黃經。生命靈數及文字獨立依生日計算。

## 限制與後續

目前本命星盤、三主星與五行星落座共用實算資料。既有其他頁面的行運、塔羅、合盤及付費整合尚需分項升級；本版不宣稱五功能與 Core Wallet 已完成。未修改 launch 驗證、會員/SELF 或資料庫結構。此分支保留 PR 審閱，尚未合併或正式部署。
